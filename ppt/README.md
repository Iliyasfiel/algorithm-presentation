# HTML 汇报文稿

入口：`index.html`。该文件已经包含全部脚本和数据，可单独复制到演示电脑离线打开。

静态预览：[preview.pdf](preview.pdf)。每页对应一张幻灯片，三维演示显示选定步骤；交互播放、视角旋转、备注和双屏功能请使用 HTML。导出命令、可选导出环境及检查记录见 [PDF 预览说明](qa/pdf-preview.md)。PDF 属于生成产物，修改 PPT 后重新导出，不直接手改。

## 使用方式

普通模式按方向键翻页，ESC 总览；三维图可拖动旋转，并用图下方按钮逐步回放。初始建树页显示第一个划分；第 13 页从空树开始，逐步显示无重建树和三维点；第 14 页展示重建对比，初始为完整插入结果，点“重置”可从空状态开始。

第 6、8、12 页分别展示范围报告、计数和最近邻 Python 代码，直接来自 `../demo/teaching.py`，经构建阶段高亮。第 15 页区分单次最坏和纯插入摊还上界，完整证明与条件见逐页 Markdown 文档。

按 P 进入模板的演讲者模式。当前页与下一页预览、备注、计时和观众屏同步均保留。出现三维演示页时，备注区域下方会显示算法回放按钮；也可以直接在当前页预览中操作。回放步数和相机视角通过模板的通信链路同步到观众屏。观众屏冻结期间不跟随演示变化，恢复后接收当前状态。

动画不会自动替代讲解：播放只推进算法事件，不会自动翻页。离开页面时暂停回放。静态模式仍允许手动切换步骤和按需重绘。若浏览器不能创建 WebGL 上下文，会显示点云的兼容投影；正式演示推荐提前确认三维模式正常。

## 维护

### AI 维护必须使用 guizang-ppt-skill

用 AI 修改 PPT 的文案、版式、样式、动效、代码展示或演讲者/观众屏交互时，**必须显式调用并先读取 `guizang-ppt-skill` 的 `SKILL.md`**，按任务加载其中的瑞士风版式、主题、演讲者模式与校验说明。不能把技能当作可有可无的参考，也不能因为仓库已有模板就跳过它。

技能来源：<https://github.com/op7418/guizang-ppt-skill>。按所用 AI Agent 的技能安装方式配置，确认 Agent 能找到名称 `guizang-ppt-skill`。缺失时应先说明并协助配置；不要在项目中硬编码个人技能安装路径。维护时保持本项目已确定的 18 页、全白主题、蓝黑灰配色及三维算法演示。

可直接发给 Agent：

> 请先阅读根目录 AGENTS.md 和本文件，显式使用 guizang-ppt-skill，按其 SKILL.md 和相关参考规范修改第 X 页的……。保持现有 18 页白色主题，修改源文件并重新构建，运行项目检查，说明实际完成的视觉和交互验证。

技能要求适用于 AI 修改 PPT。直接打开成品、运行现有构建或测试仍不需要安装技能；本地模板保证成品与构建不依赖技能目录。

### 源文件与构建

- 改文案及讲稿：`content.js`。
- 改页面排版：`deck.css`。
- 改三维和树形回放：`viz.js`。
- 改算法、事件或实验：修改 `../demo/`，先生成数据。
- 重新构建：从根目录运行 `python ppt/build_deck.py`，需要本机 Node.js 读取逐页 JS 数据。
- `assets/template-swiss.source.html` 是本次使用的模板快照，不依赖外部技能目录存在。
