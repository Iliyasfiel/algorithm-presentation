# HTML 汇报文稿

入口：`index.html`。该文件已经包含全部脚本和数据，可单独复制到演示电脑离线打开。

## 使用方式

普通模式按方向键翻页，ESC 总览；三维图可拖动旋转，并用图下方按钮逐步回放。初始建树页显示第一个划分；第 13 页从空树开始，逐步显示无重建树和三维点；第 14 页展示重建对比，初始为完整插入结果，点“重置”可从空状态开始。

第 6、8、12 页分别展示范围报告、计数和最近邻 Python 代码，直接来自 `../demo/teaching.py`，经构建阶段高亮。第 15 页区分单次最坏和纯插入摊还上界，完整证明与条件见逐页 Markdown 文档。

按 P 进入模板的演讲者模式。当前页与下一页预览、备注、计时和观众屏同步均保留。出现三维演示页时，备注区域下方会显示算法回放按钮；也可以直接在当前页预览中操作。回放步数和相机视角通过模板的通信链路同步到观众屏。观众屏冻结期间不跟随演示变化，恢复后接收当前状态。

动画不会自动替代讲解：播放只推进算法事件，不会自动翻页。离开页面时暂停回放。静态模式仍允许手动切换步骤和按需重绘。若浏览器不能创建 WebGL 上下文，会显示点云的兼容投影；正式演示推荐提前确认三维模式正常。

## 维护

- 改文案及讲稿：`content.js`。
- 改页面排版：`deck.css`。
- 改三维和树形回放：`viz.js`。
- 改算法、事件或实验：修改 `../demo/`，先生成数据。
- 重新构建：从根目录运行 `python ppt/build_deck.py`，需要本机 Node.js 读取逐页 JS 数据。
- `assets/template-swiss.source.html` 是本次使用的模板快照，不依赖外部技能目录存在。
